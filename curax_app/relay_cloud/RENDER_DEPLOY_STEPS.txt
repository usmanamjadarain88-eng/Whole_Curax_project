================================================================================
RENDER DEPLOY - STEP BY STEP (use this folder: relay_cloud)
================================================================================

WHAT THIS SERVICE IS:
  WebSocket-only alert relay (like a socket). No FCM, no Firebase env vars.
  - Phone app keeps wss open with { "bot_id", "api_key" }.
  - Backend sends { "action":"alert", "bot_id", "api_key", "type", "message" }.
  - Relay forwards to that phone → popup in admin/user app.

FOLDER TO USE:  curax_app\relay_cloud
FILES IN IT (all 3 are needed):
  - server.py
  - requirements.txt
  - Procfile

Render needs your code in a Git repo (GitHub). Two ways:

--------------------------------------------------------------------------------
OPTION A - New GitHub repo with only the relay (simplest)
--------------------------------------------------------------------------------

1. Create a new repo on GitHub (e.g. name: curax-relay).
   - Do NOT add README/license (empty repo).

2. On your PC, open PowerShell in the relay_cloud folder:
   cd "C:\Users\PMYLS\OneDrive\Desktop\rightone\curax_app\relay_cloud"

3. Run:
   git init
   git add server.py requirements.txt Procfile
   git commit -m "CuraX cloud relay"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/curax-relay.git
   git push -u origin main
   (Replace YOUR_USERNAME with your GitHub username.)

4. In Render.com:
   - Click "New +" → "Web Service".
   - "Connect a repository" → choose GitHub → select the repo "curax-relay".
   - Render will show a form:
     * Name: e.g. curax-relay
     * Region: choose nearest
     * Branch: main
     * Root Directory: leave BLANK (files are at repo root)
     * Runtime: Python 3
     * Build Command:  pip install -r requirements.txt
     * Start Command:  python server.py
   - Click "Create Web Service".

5. Wait for "Deploy live". Your URL will be:
   https://curax-relay.onrender.com
   (or whatever name you gave; it appears at the top of the service page.)

6. Use that URL in:
   - Android app: Server URL field (e.g. wss://curax-relay.onrender.com)
   - Backend Vercel env: RELAY_URL=wss://curax-relay.onrender.com

--------------------------------------------------------------------------------
AUTO-DEPLOY AFTER YOU CHANGE server.py / requirements.txt / Procfile
--------------------------------------------------------------------------------

On Render (recommended):
  1. Dashboard → your Web Service (curax-relay) → Settings.
  2. Build & Deploy → Auto-Deploy: ON.
  3. Branch: main (or your default branch).
  4. Every git push to that branch rebuilds and redeploys automatically.

Workflow when you edit files in C:\Work\curax_app\relay_cloud:
  A) If Render is connected to a repo that contains ONLY relay_cloud (Option A):
     - Copy updated server.py, requirements.txt, Procfile into that repo folder.
     - git add -A && git commit -m "relay update" && git push
     - Render deploys in ~2–5 minutes (watch Logs tab).

  B) If Render uses the big monorepo (Option B):
     - Commit from repo root; Root Directory stays curax_app/relay_cloud.
     - git push → Render auto-deploys only that subfolder.

No Firebase env vars needed. Only:
  - Build Command:  pip install -r requirements.txt
  - Start Command:  python server.py   (or Procfile: web: python server.py)

Test after deploy:
  - Browser: https://YOUR-SERVICE.onrender.com/status  → {"relay":"ok","delivery":"websocket"}
  - Phone app Connect once with Bot ID + API Key → relay Logs show "linked …"

--------------------------------------------------------------------------------
OPTION B - You already have the full project on GitHub
--------------------------------------------------------------------------------

1. Make sure "relay_cloud" is inside your repo (e.g. rightone/curax_app/relay_cloud).

2. In Render.com:
   - "New +" → "Web Service".
   - Connect the repo that contains relay_cloud.
   - In the form set:
     * Root Directory:  curax_app/relay_cloud
     * Build Command:   pip install -r requirements.txt
     * Start Command:   python server.py
   - Create Web Service.

3. Use the URL Render gives you (e.g. https://something.onrender.com) in the app and desktop.
