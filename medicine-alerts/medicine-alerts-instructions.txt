# Final Instructions: Medicine Alerts with GitHub Actions

Follow these steps to keep your medicine reminders in sync and receive alerts via GitHub Actions:

---

## 1. Prepare Your Repository
- Your main app (myone.py) is now in the medicine-alerts folder.
- All reminders and alert settings are stored in your SQLite database (curax_alerts.db) in the same folder.

---

## 2. How Reminders Sync to GitHub
- Whenever you add or update a medical reminder in the app, it is saved to the database.
- The app automatically exports all reminders (from both alert_settings and medical_reminders) to medicine_times.json in the repo.
- The app then pushes medicine_times.json to GitHub automatically.

---

## 3. GitHub Actions Workflow
- The .github/workflows/alert.yml workflow runs every 5 minutes.
- It reads medicine_times.json and sends alerts (e.g., via email) using the script in .github/scripts/alerts.py.

---

## 4. What You Need to Do
1. Make sure you have git installed and configured on your PC.
2. When you add or edit reminders in the app, the sync is automatic—no manual steps needed.
3. If you want to force a sync, you can call the export_medicine_alerts_to_json_and_push function manually.
4. To rebuild your .exe, use:
   ```
   pyinstaller --onefile --windowed --name "CuraX_Medicine_Alerts" myone.py
   ```

---

## 5. Troubleshooting
- If you see git errors, make sure your repo is cloned and you are logged in to GitHub.
- If you change the database location, update the db_path in the export function.
- If you want to change the alert method (e.g., Telegram, SMS), update .github/scripts/alerts.py.

---

## 6. Summary
- All reminders are now exported to medicine_times.json and pushed to GitHub automatically.
- GitHub Actions will send alerts based on this file, even if your PC is off.

You are ready to use GitHub for real-time, always-on medicine alerts!
